## 🚀 Getting Started

### ✅ Prerequisites

* Node.js `v22.x` (Backend)
* Node.js `v22.x` (Frontend & Admin)
* Web crypto wallet (MetaMask, TrustWallet, etc.)

### 🧠 Backend Setup

```bash
npm install

# Start services
npm start              # Main server
```

### 🎨 Frontend Setup

```bash
cd client
npm install
npm start
```
